# lingdiff
Tool for linguistic comparison between languages.

## Environment

**Depends on an external drive staying mounted**, same setup as the `ye_olde` project:
`/media/dahrs/My_passport` is too small on root (`/`) for Python envs/data, so:

- `.venv` -> `/media/dahrs/My_passport/lingdiff-venv`
- `data/sources/` (raw WALS/PHOIBLE/Glottolog/ASJP dumps + LLM cache, gitignored,
  regenerated by `pipeline/fetch_sources.py`) -> `/media/dahrs/My_passport/lingdiff-data-sources`
- `uv`'s package cache is also relocated machine-wide via `UV_CACHE_DIR` in `~/.bashrc`
  -> `/media/dahrs/My_passport/uv-cache`

If the drive isn't mounted, `uv run ...` and the pipeline scripts will fail outright.
`data/languages/*.json` and `data/index.json` (the small, committed outputs the website
actually reads) live in the repo as normal and don't depend on the drive.

## Data pipeline

```
uv run python -m pipeline.run_pipeline
```

Downloads WALS (CLDF), PHOIBLE, and Glottolog source data into `data/sources/raw/` (cached —
reruns skip files already present), builds one `LanguageProfile` per ISO 639-3 code listed in
`pipeline/run_pipeline.py`, and writes `data/languages/<code>.json` + `data/index.json`.

Currently covers a ~25-language smoke-test set to validate the schema/merge logic end-to-end
(see the full plan for the broader build-out: URIEL/lang2vec vectors, Wikidata lookups, scoped
LLM enrichment, then scaling to the full target language list).

No LLM calls happen yet at this stage — that's a later pipeline increment, and even once added,
only runs offline during the data build, never at site runtime.
